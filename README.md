# 🛸 Rick and Morty API Explorer

El explorador de la API de Rick & Morty es un proyecto de aplicación web que permite buscar personajes por nombre y visualizar información detallada mediante tarjetas dinámicas e interactivas.

# ⚙ Instalación del proyecto

## 1️⃣ Clonar el repositorio

Abre la consola de tu ordenador o bien por el comando Win + R, abriendo con click derecho en el escritorio o buscando "Terminal" en la barra de navegación. A continuación introduce este comando y pulsa Enter: 

```bash
git clone https://github.com/usuario/rick-and-morty-api.git
```

---

## 2️⃣ Acceder al directorio del proyecto

Nota: con escribir las primeras letras y tabular se autocompleta la ruta a la carpeta.

```bash
cd rick-and-morty-api
```
---

## 3️⃣ Abrir el proyecto en Visual Studio Code

Instálalo desde internet o la store de tu ordenador si no lo tienes.

```bash
code .
```

---

# ▶ Ejecución de la aplicación

## 🔹 Método recomendado:

Abrir directamente el archivo:

```text
index.html
```

haciendo doble clic sobre él desde el explorador de archivos.

---

## 🔹 Método alternativo

Si utilizas Visual Studio Code:

1. Instala la extensión **Live Server**.
2. Haz clic derecho sobre el archivo `index.html`.
3. Selecciona:

```text
Open with Live Server
```

La aplicación se abrirá automáticamente en tu navegador.

---

# 🌐 Uso desde el navegador

Una vez iniciada la aplicación:

1. Introduce el nombre de un personaje en la barra de búsqueda.
2. Pulsa el botón de búsqueda o Enter.
3. La aplicación realizará una petición a la API.
4. Se mostrarán automáticamente las tarjetas de los personajes encontrados.

---

# ✨ Características

✅ Búsqueda de personajes por nombre utilizando la API oficial de Rick and Morty.  

✅ Visualización de personajes mediante tarjetas individuales. 

✅ Interfaz dinámica y responsive, adaptada para móviles y tablets.  

✅ Consumo de API mediante peticiones asíncronas mediante JavaScript.

---

## 🧩 Estructura de las tarjetas

Cada tarjeta contiene:

| Elemento | Descripción |
|---|---|
| 🖼 Imagen | Imagen oficial del personaje |
| 🧑 Nombre | Nombre completo |
| 🟢 Estado | Vivo, muerto o desconocido |
